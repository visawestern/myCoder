## 1. Назначение и концепция

**myCoder** — бесплатный, независимый, open-source AI-кодинг-воркспейс для macOS. Продукт сочетает:

- AI-чат с streaming-ответами, Markdown-рендером, tool-calls, изображениями, файлами и Plan-вопросами;
- проектную историю (SQLite), Git-операции, терминал с гейтами безопасности;
- настройку провайдеров (локальные, кастомные, remote, OpenAI-совместимые, ACP, веб-транспорты);
- skills, MCP-серверы, slash-команды, FTS5-поиск, статистику использования, 10 языков локализации.

**Концепция качества:** нет намеренных заглушек. Неполные функции явно помечаются
`PARTIAL`/`MISSING`/`FUTURE` в каноническом реестре, а не маскируются статусом `PASS`.

## 3. Архитектура

```
myCoder/
  Sources/
    App/        состояние приложения, macOS-команды, модальные окна
    Models/     доменные модели и контракты настроек (Message, MessagePart, Settings)
    Services/   провайдеры, хранилище, Git, индексация, инструменты, гейты
    Views/      SwiftUI-экраны и переиспользуемые компоненты
    Resources/  ресурсы и встроенные каталоги (Info.plist, AppIcon)
  Tests/        логика, хранилище, провайдеры, безопасность, интеграция
```

Ключевые сервисы:
- `WebToolProtocolEmulator` — эмуляция tool-протокола для веб-чата: парсинг
  `` ```tool ```` JSON и XML `<tool_call>`-формата, системный промпт, валидация/безопасность.
- `WebChatDriver` — агентный цикл поверх веб-чата (посылка, опрос, обработка tool-calls, лимиты итераций).
- `DatabaseBridge` / `DatabaseManager` / `ProjectDatabaseManager` — маршрутизация и персистентность.
- `ProjectWebToolExecutor` — исполнение инструментов (read/grep/glob/edit/git/todo/task).
- `MarkdownText` — лёгкий Markdown-рендер (блоки, inline, таблицы, код, списки).
- `MimoServeClient` / `DirectWebAPIClient` / `SSEClient` — API-клиенты и веб-транспорты.

## 4. Активности и возможности

> Нумерация активностей соответствует `docs/activity-checklists/`.

### 4.1. Оболочка приложения и навигация (`01-app-shell`, `02-sidebar`)

- Рабочие области (workspaces), задачи, архив, уведомления, поиск по сессиям/проектам.
- Flows: открытие/создание проекта, маршрутизация сессии проекта, восстановление после перезапуска.
- Верхняя панель, task-header, статус-бар, окно нового проекта.
- macOS-команды (меню), оверлеи, restore и роутинг окон.

### 4.2. Чат (`03-chat`, `06-web-chat`, `34-web-providers-chat-input`, `44-chat-and-web-agent-boundaries`)

- Ввод и отправка сообщений, streaming-ответы, Markdown-рендер, файловые вложения, изображения, Plan-вопросы.
- **Агентный режим веб-чата:** система промптов эмулирует OpenCode-структуру (роль, окружение — рабочая
  директория/git/дата, политика инструментов, список инструментов, оба формата вызова).
- **Tool-call протокол:** распознавание и ```` ```tool ```` JSON и XML `<tool_call>…<arg_key>…<arg_value>`.
  Алиасы инструментов (`execute_command` → `run_command` и т.п.) регистронезависимы.
- Обработка tool-результатов, лимиты итераций, Stop/Restart.
- **Разметка сообщений:**
  - Заголовки, списки (маркеры нумерованных списков — пурпурные), цитаты, inline-код.
  - **Таблицы** — рендер markdown-таблиц (шапка + зебра-строки + вертикальные разделители).
  - **Кодовые блоки** — шапка с языком и кнопкой копирования всего блока.
  - **Thinking-спойлер** — reasoning пурпурным; во время стрима показывается полностью, после
    завершения сворачивается в 4 строки, раскрытие по клику.
  - **Tool-inspector** — компактные шаги инструментов слева, детали аргументов/результата справа.

### 4.3. Правая панель: Git, прогресс, Premium (`03-right-panel`)

- Git-статус, ветки (создание/переключение), commit, push/pull/publish, review-флоу.
- Прогресс операций и Premium-флоу (myCoder Auto Free).

### 4.4. Нижняя панель: терминал и Git (`04-bottom-panel`, `09-shell-status`, `58-shell-status-audit`)

- Terminal и Git-вкладки, команды, остановка, история, изменения.
- Гейт AccessLevel: `run_command` ограничен, bounded execution.

### 4.5. Настройки (`05-settings`, `04-settings-providers`, `05-web-login`, `24-model-parameters`)

- 10 видимых вкладок Settings: General, Providers, Model, Skills, MCP, Indexing, Storage, Usage, Commands, Plugins.
- Провайдеры: локальные, кастомные, remote, OpenAI-совместимые, ACP, веб-транспорты.
- Веб-логин (встроенный браузер), детект моделей/усилия до захвата сессии, cohérence модели/effort.
- Экспорт/импорт конфигурации, резервные копии.

### 4.6. Верхняя панель, task-header, статус-бар, проект (`06-topbar…`, `08-project-session`)

- Top bar, task header, статус-бар, окно нового проекта.
- Маршрутизация проектной сессии и хранилища (`45-history-provider-project-routing`).

### 4.7. MCP, навыки, каталоги (`07-mimo-auto`, `18-skills-management`, `19-mcp-management`)

- Каталог/установка/управление skills и MCP-серверов, слэш-команды.

### 4.8. Индексация, поиск, использование (`15-indexing`, `26-file-index-logic`, `27-fsevents-watcher`, `17-usage-costs`, `36-usage-screen`, `37-cost-per-model`)

- Проектная файловая индексация + FSEvents-наблюдатель, FTS5-поиск по сообщениям.
- Статистика использования и стоимости по моделям.

### 4.9. Хранилище, резервное копирование, откат (`16-storage-backup-cleanup`, `29-project-delete`, `45-…routing`, `48-…boundaries`)

- WAL, целостность, авто-бэкапы, restore, per-project undo, request history.
- Delete-флоу проектов, честный размер базы с учётом `-wal`/`-shm`.

### 4.10. Веб-транспорты, браузер, captcha, отправка (`05-web-login`, `20-browser-transport`, `21-captcha-display`, `23-send-button`, `40-verified-browser-send`, `41-serve-send-feedback`)

- Встроенный браузер (WebKit) с полным allow навигации, попапы in-place, авто-ответ диалогов.
- Верификация отправки по появлению chat-id в URL; retry; честный статус.
- Отображение captcha, интерактивный мост.

## 5. Формат системного промпта веб-агента (справочно)

Промпт эмулирует OpenCode-структуру: роль → «environment» (рабочая директория, git-репо, дата) →
политика инструментов → формат вызова (JSON-блок и XML) → список инструментов → обработка
разбитых больших сообщений (`[PART x/N]` / `[FINAL PART N/N]`).

## 6. Дорожная карта улучшений (запланировано / реализуется)

> Эти пункты являются приоритетом развития продукта. Статусы `✅ в коде` / `📋 запланировано`.
>
> **Доставка списка инструментов модели** — `✅`: `WebToolProtocolEmulator.systemPreamble` со
> списком инструментов и окружением передаётся моделью И в web-UI (как системное user-сообщение
> сеанса), И в API-путь (`ChatHistoryBuilder.messages` получает его как роль `system`, поверх
> пользовательского `systemPrompt`). Без этого «бесплатные» API-модели отвечают «у меня нет
> доступа к файлам».
>
> **Каталог бесплатных моделей (Auto Free)** — `✅`: доверенный список синхронизирован
> с живым каталогом (`muse-spark-1.3-contributor-free`, `muse-spark-1.2-contributor-free`,
> `ling-3.0-flash-fin-free` добавлены; отозванные сервером `hy3-free`, `ling-3.0-tiny-free`
> удалены), а `isEligibleFreeModel` принимает любой живой `-free`-маршрут, поэтому новые
> бесплатные модели появляются после обновления без обновления приложения. Платные модели
> (без суффикса `-free`) по-прежнему недоступны анонимно.
>
> **Сохранение моделей веб-провайдера** — `✅`: `WebProviderStore.sanitize` больше не
> пропускает ручные модели через DOM-валидатор и не сносит выбранную модель при пустом
> списке — данные пользователя сохраняются.
