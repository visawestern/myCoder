Дополнительно закрыто:

- **WebKit удалён полностью.** В `myCoder/Sources` нет `WKWebView`, `import WebKit`
  и `#if canImport(WebKit)`. Вход веб-провайдера подтверждается живой проверкой
  вкладки (`WebLoginVerificationLogic`), в конфиге хранится только
  `loginConfirmedAt`; показ страницы — только каст AntiBrowser.
- **Откат сообщений вместе с правками.** `RollbackUndoEntryRef.messageID` и
  `ProjectUndoEntryRecord.messageId`; старые записи без привязки сравниваются по
  времени с включением той же секунды.
- **Универсальное обнаружение моделей.** Селекторы каталога → при неудаче снимок
  DOM уходит `mercury-3` строгим JSON-запросом → проверка тем же
  `WebModelListParser`; пустой DOM/недоступная модель → `nil`, без выдумок.
- **Локализация.** `AppLocalization+Translations3.swift`; исправлен поиск по
  английскому значению; `HardcodedStringAuditTests` и тесты полноты таблицы.
- **Производительность контекста.** Граф больше не пересобирается в путях
  чтения; `ImpactAnalyzer` использует `allActiveSymbols()`/`allEdges()`;
  маскирование переведено на байтовый проход; `ContextBoardPerformanceTests`.
- **Устаревшие связи не выдают себя за действующие.** `ImpactAnalyzer`
  отбрасывает рёбра, у которых хотя бы один конец не принадлежит активному
  файлу или активному символу. Тест создаёт временный проект, помечает
  `Settings.swift` устаревшим и требует, чтобы его импорт не попал в отчёт.
  До правки тест падал — это была настоящая ложная зависимость.
- **Гонка уведомлений устранена на уровне типа.** `NotificationService`
  переведён на `@MainActor`: `@Published` не потокобезопасен, а компилятор
  теперь запрещает фоновые вызовы. Прежний тест менял массив из десяти
  `DispatchQueue.global()` и ронял весь прогон с SIGSEGV; новый тест
  отправляет конкурентные запросы через `withTaskGroup` на главный актор и
  проверяет ровно 10 уведомлений без потерь.
- **Системный промпт слит со стилем Claude Fable 5.2 и уплотнён.**
  Добавлен компактный блок поведения `responseConduct` (главное — сразу,
  краткость, честность без «я честно», автономная доводка до результата,
  без навязчивого продолжения диалога, запрет вредоносного кода и обхода
  гейтов). Блок встроен в нативный `collaborationCore`; для веб/OpenAI-
  совместимых маршрутов — однострочный вариант `compactConductLine`
  (полный блок вытолкнул бы вставку за бюджет провайдеров ~4000 Б).
  Промпт субагента дополнен «не выдумывай находки, честно называй
  пробелы». Компактность закреплена тестами-стражами: `responseConduct`
  ≤1200 символов, нативный базовый промпт ≤12 000, минимальный профиль
  ≤18 000, полный веб-промпт ≤42 000 (целевые 65 000 не достигаются).
- **Модель субагентов в режиме маршрутов.** Логика выбора транспорта
  субагента вынесена из вью в чистый модуль `SubagentTransportResolver`
  (переносим, тестируем отдельно): в режиме «одна модель для всего»
  субагент наследует транспорт вызывающей модели; в режиме маршрутов —
  использует назначение роли «Context research», и только если это прямая
  OpenAI-совместимая модель; любой другой транспорт — явный `.unsupported`
  с причиной, без подмены. 5 новых тестов.
- **Документы приведены в согласованное состояние.** Активные чеклисты закрыты,
  исторические — помечены архивом, внешние ограничения вынесены сюда.

- **A14 — подпись/нотаризация:** нужны Apple credentials владельца.
- **A15 — апдейтер браузера:** отдельное продуктовое решение владельца.
- **engine25 / `ShouldSaveWindowPlacement`:** нужна полная пересборка Chromium
  и визуальная приёмка владельца.
- **Живые проверки AntiBrowser:** `window_check 0/1`,
  `verify_login_pages.sh 4/4`, `browser_fetch` на реальной странице — требуют
  движка, сети и окна владельца.
- **Полная визуальная проверка GUI:** каст, вход, статус движка, наведение
  мышью, курсор, живой скролл — требуют окна и владельца; headless-прогон их
  не заменяет.
- **Живая проверка всех транспортов провайдеров:** нужны ключи и сессии
  владельца.
- **Динамический граф зависимостей:** рефлексия, привязки и внешние сервисы
  в статический индекс не входят по определению.
